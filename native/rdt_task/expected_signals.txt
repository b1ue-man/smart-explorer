# Erwartete Abnahmesignale der Stapel-Suite rechte-desktop-tresore-task (plan.md D3).
#
# Die Suite waehlt Tests nur ueber diese genauen Namen aus, nie ueber Praefixfilter
# (D3, W14: mount_vault_task_* wird nie ausgewaehlt). Die Pruefung
# rdt_suite_inventory_complete vergleicht diese Liste mit dem Code:
#   - jeder Test mit einem Stapelpraefix (perm_task_, drive_task_, vault_task_,
#     screen_task_, desktop_task_, launcher_task_, licenses_task_, rdt_suite_) im Code
#     steht hier und laeuft je Job in genau einer Stufe;
#   - jeder Eintrag im Abschnitt [umgesetzt] existiert im Code;
#   - ein Eintrag im Abschnitt [noch nicht umgesetzt], der im Code fehlt, erscheint im
#     Bericht als "nicht ausgefuehrt" mit dem Grund "nicht umgesetzt" und dem Paket.
#     Das Paket, das den Test bringt, verschiebt die Zeile nach [umgesetzt] und setzt
#     dabei Optionen und Stufe endgueltig.
#
# Zeilenformat (Felder durch Leerzeichen getrennt):
#   <name> <job>:<stufe>[,<job>:<stufe>...] [option ...]
# Ein Name darf in mehreren Zeilen stehen (zum Beispiel Windows umgesetzt, Linux offen),
# aber je Job nur an genau einem Ort.
#
# Optionen:
#   art=lib       Bibliothekstest des Crates smart_explorer (Standard); laeuft mit vollem
#                 Testpfad und --exact
#   art=modul     Bestandsharness: alle Tests, deren voller Pfad das Bruchstueck modul=
#                 enthaelt
#   art=check     Pruefung der Suite selbst (Python, Register CHECKS eines rdt_task-Moduls)
#   art=skript    Pruefung eines fertigen Pruefskripts (skript=PFAD), das den Namen meldet
#   art=junit     JVM-/Robolectric-Test der Android-App (Methode oder Klasse)
#   art=instr     Instrumentierung auf dem Emulator (Methode oder Klasse)
#   ignored       Test traegt #[ignore]: laeuft mit --include-ignored
#   threads=N     --test-threads=N
#   env=NAME=WERT Umgebungsvariable (mehrfach). Platzhalter: {se} absoluter Pfad des
#                 Debug-se, {gui} absoluter Pfad des Debug-smart_explorer, {tmp} frischer
#                 Ordner je Aufruf, {native}, {repo}, {work}
#   root          Linux: der Test laeuft ueber sudo -E als root (Testprogramm direkt)
#   pfad=a::b::n  erwarteter voller Testpfad (Inventur prueft ihn)
#   modul=::a::b:: Pfadbruchstueck fuer art=modul
#   fixture=a,b   Laeufer-Fixtures mit festem Umgebungsvertrag (rdt_task/common.py):
#                 share, sftp, bus, xvfb, nodisplay, home, runtime-tmpfs, fuse,
#                 fuse-timeout, dokany, own-suite, sudo, android-servers,
#                 android-servers-optional (common.py); interop, keep, marker (vault.py)
#   skript=PFAD   Pruefskript fuer art=skript
#   paket=Uxx     Paket, das den Test bringt (Pflicht in [noch nicht umgesetzt]);
#                 "offen" = kein Paket benannt
#   quelle=TEXT   Herkunft (R/L/T = Zeile in strang-rechte/-laufwerke/-tresore.md,
#                 D3, Uebergabe-Uxx, C4, C5, Code)
