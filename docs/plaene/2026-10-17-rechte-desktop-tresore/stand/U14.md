## 3. Getroffene Entscheidungen

1. Spool im Format `SIV_GCM`; jeder geschriebene Block wird mit neuer Nonce verschlüsselt; Blockvertauschung scheitert am AAD; Kürzen an einer Blockgrenze ist im Format nicht erkennbar (Grenze).
2. Spool-Schlüssel 32 Byte je Laufwerk, AES-KW mit `spool-wrap`, Datei `<spool-root>/<mount-id>/spool-key.wrapped`; Inhalts- und Textschlüssel per HKDF-SHA256 mit 64 Byte Ausgabe (`se-mount-spool-content-v1`, `se-mount-journal-v1`). Eine Schlüsseldatei, die nicht entwickelt, bleibt liegen.
3. Tresorerkennung im Host über das Backend-Schema `Vault`; kein neues Feld in `MountHostConfig`.
4. U02 offener Punkt 5: `detail`-Texte werden für Tresor-Laufwerke versiegelt (Trait-Methoden mit Identitäts-Standard).
5. `PrepareLock`: lange Abfrage des Hosts über `MountHostExt` (höchstens 30 s, Host 25 s), Antwort `PrepareLock { deadline_ms, keep_unsaved }` oder `Idle`, Ergebnis `LockPrepared` auf derselben Verbindung; ein Teilnehmer für alle Laufwerke einer Site, gemeinsame Frist; ohne Antwort Abbruch (Linux faules Aushängen und `fusectl`, Windows Job-Objekt), Bestätigung erst danach.
6. U06 Frage 1: Ein beim Anmelden gesperrter Tresor stellt seine Laufwerke zurück (`vault_locked`, mit Änderungen `RequiresUnlock`) und bindet sie nach dem Entsperren ein.
7. U06 Frage 2: Sperren behält den Registry-Eintrag; jedes Entsperren bindet wieder ein und veröffentlicht die versiegelten Änderungen; `se drive unmount` vergisst das Laufwerk.
8. `MountRecovery::RequiresUnlock { pending }`, JSON `{"requires_unlock":{"pending":<n>}}` (Abweichung vom Plantext, weil die CLI die Zahl braucht).
9. Linux: Tresor-Laufwerk nur unterhalb des Tresor-Orts; tmpfs-Prüfung im Host.
10. Sperr-Ablehnung nennt Bezeichnung und Anzahl, nie Fehlertexte mit Pfaden.
11. `MountPathFor` antwortet mit `IpcResponse::Mounts`; `ensure_mounted_for` nur für `vault://`.
12. U20-Übergabe: `publish_vault_mount` bei jedem Status `Mounted`/`MountedAt`/`Conflict` eines Tresor-Laufwerks (`update_status`), `withdraw_vault_mount` an seinem Ende (`after_exit`).
